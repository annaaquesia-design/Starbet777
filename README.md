# StatBet777 — Demo

Protótipo recreativo com saldo virtual. Não possui depósitos, saques, prêmios ou integração com operadores.

Abra `index.html` no navegador.

Inclui:
- sportsbook com eventos e odds fictícias;
- cupom de aposta;
- saldo demo de R$ 10.000;
- histórico;
- área de jogos demo com referências visuais a Fortune Tiger, Fortune Rabbit e Aviator;
- layout responsivo.

Para uma versão de produção, substitua os dados fictícios por um backend próprio e mantenha a experiência sem dinheiro real.
